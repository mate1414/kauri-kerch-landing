КАУРИ-КЕРЧЬ — адаптивный лендинг

Состав проекта
- index.html  — разметка и весь текст сайта
- styles.css  — адаптивная стилизация
- script.js   — слайдеры, мобильное меню, вкладки, интерактивная карта и обработка формы
- assets/     — локальные запасные изображения, вырезанные из переданного скриншота

Запуск
Откройте index.html в браузере. Для полноценной работы карты, внешних фотографий и шрифтов требуется подключение к интернету.

Форма обратной связи
Форма проверяет обязательные поля и формирует письмо на e-mail через mailto:. Сообщение не отправляется автоматически — пользователь подтверждает отправку в своей почтовой программе. Для настоящей отправки без mailto потребуется подключить серверный обработчик или сервис форм.

Публикация
Загрузите файлы проекта и папку assets/ на хостинг, сохраняя структуру каталогов. Если сайт будет опубликован не в корне, пути к локальным fallback-изображениям останутся относительными к index.html.
